# ChemMind Frontend

Next.js 14 chat interface for ChemMind.

## Setup

```bash
cd frontend
npm install
npm run dev
```

## Backend

Start the Python backend first:

```bash
python backend.py
```

The frontend connects to `http://localhost:8000` by default.

## Features

- Chat interface with user/AI message bubbles
- Material System filter dropdown
- Simulation Software filter dropdown
- Green/dark professional scientific theme
- Markdown rendering for AI responses
- Typing indicator animation
